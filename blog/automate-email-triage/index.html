Automate Email Triage with Make.com and AI

August 08, 2026

Quick Verdict

For most 1–50 person ops teams, using Make.com with OpenAI’s GPT-4o gives the best balance of accuracy and ease of setup for email triage. Claude 3.5 Sonnet is a cheaper alternative if you can tolerate slightly less nuanced classification.

Overview

Email triage is a time sink for small operations teams. Incoming messages need to be classified (support, billing, sales inquiry, internal), prioritized (urgent, normal, low), and routed to the right person or tool. Doing this manually scales poorly.

Make.com (formerly Integromat) lets you build automated workflows without code. Combined with an AI model, you can create a system that reads each email’s subject and body, categorizes it, and sends it to Slack, ClickUp, or a ticketing system. The core flow:

  • Trigger: New email via Gmail, Outlook, or IMAP module.
  • AI step: Send email text to an LLM API (OpenAI, Claude, etc.) with a prompt to return JSON with category, priority, and summary.
  • Routing: Use Make.com’s router to send to different apps based on the AI output.

Below I compare two popular AI providers for the classification step. Both work well with Make.com’s HTTP module.

Head-to-Head: OpenAI GPT-4o vs. Claude 3.5 Sonnet

Strengths & Weaknesses

Criteria OpenAI GPT-4o Claude 3.5 Sonnet
Classification accuracy Excellent with nuanced categories (e.g., “billing vs. sales” when context overlaps) Very good, slightly less reliable on ambiguous phrasing
Structured output (JSON) Good with system prompts; occasional formatting errors Excellent – rarely deviates from requested JSON schema
Latency per email ~1–2 seconds ~2–3 seconds
Cost per 1,000 emails (avg 200 tokens) $0.30 (input) + $1.20 (output) ≈ $1.50 $0.15 (input) + $0.60 (output) ≈ $0.75
Ease of integration in Make.com Native OpenAI module available (easier), or HTTP module HTTP module only (requires API key and correct endpoint)

Verdict on the comparison: GPT-4o is the default for teams that need high accuracy and can afford the premium. Claude is a strong cost-saver if your email categories are clear-cut and you want to avoid occasional JSON fixes.

Price Comparison

Beyond AI API costs, you need a Make.com plan. Here’s the full picture for a team processing ~500 emails/month:

Component Cost/month Notes
Make.com Core plan (10k ops) $9 Sufficient for 500 emails + routing actions
OpenAI GPT-4o (500 emails) ~$0.75 Based on ~200 tokens per email
Claude 3.5 Sonnet (500 emails) ~$0.38 Half the cost of GPT-4o
Total with GPT-4o ~$9.75
Total with Claude ~$9.38 Negligible difference at low volume

At higher volumes (5,000 emails/month), the AI cost gap widens: ~$7.50 for GPT-4o vs. ~$3.75 for Claude. Make.com’s plan may need an upgrade to the Pro plan ($16/month) if you exceed 10k operations.

Who Each Is For

OpenAI GPT-4o

  • Teams handling complex, multi-department email (e.g., support + sales + legal).
  • You want the native Make.com OpenAI module for simpler setup.
  • Budget is not a primary concern – you prioritize accuracy over cost.

Claude 3.5 Sonnet

  • Teams with well-defined, distinct categories (e.g., “support” vs. “spam”).
  • You’re comfortable setting up an HTTP module and parsing JSON.
  • You want to minimize AI spend without sacrificing too much quality.

Both approaches let you route emails to Slack, ClickUp, or a shared inbox. If you already use ClickUp for task management, you can create tasks directly from triaged emails. For teams that also need to transcribe voicemails or meeting notes from email attachments, Fireflies.ai can be integrated as a downstream action.

Further Reading

  • ClickUp – Task management to receive routed emails as tasks.
  • Fireflies.ai – Meeting transcription and note-taking, useful if email triage includes meeting requests.
  • OpenAI API documentation – For crafting your classification prompt.
  • Anthropic Claude API docs – For structured output best practices.
